# **App Name**: AuditAccess

## Core Features:

- Inclusive Audit Pipeline: Utilizes a server-side Playwright and axe-core tool to perform automated accessibility scans tailored to specific disability personas.
- Persona Narrative Tool: Uses generative AI as a tool to interpret technical violations into qualitative human impact summaries for various disability categories.
- Weighted Scoring Engine: Calculates the DISA fairness score based on six weighted metrics: access, task completion, accommodation, equity, recovery, and governance.
- PDF Insight Reports: Generates formal audit documentation with @react-pdf/renderer including overall score trends and top 5 remediation priorities.
- AI System Inventory: Centrally manage multiple AI systems with cloud persistence for tracking audits and historical compliance across different chatbot versions.
- Security-First Dashboard: Real-time visualization of compliance scores and past audit history protected by Firebase-driven secure access.
- Persona-Driven Selection: Contextual configuration allowing users to target audits for specific user needs like Dyslexia or Motor Impairments.

## Style Guidelines:

- Primary color: Vibrant Tech Blue (#6B8AFD) representing clarity and innovation in a digital workspace.
- Background: Deep Ink Charcoal (#0A0D12), providing a sophisticated high-contrast canvas that minimizes eye strain and exudes professionalism.
- Accent: Crisp Cerulean (#43A5D4) to emphasize calls-to-action and secondary navigation elements.
- Headline font: 'Space Grotesk' (sans-serif) for a scientific, tech-forward aesthetic. Body font: 'Inter' (sans-serif) for optimal legibility across complex data reports.
- Abstract, minimalist geometric icons that focus on data integrity and user empathy.
- Bento-grid dashboard style for organized, data-heavy reporting with significant negative space.
- Precise, micro-interactions and smooth progressive progress bars for scoring animations to provide reassuring feedback during intensive scans.
